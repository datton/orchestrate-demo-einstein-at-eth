# Einstein at ETH Zurich

A small static two-page history site on Albert Einstein's connection to ETH Zurich, built by the Orchestrate Solutions team.

## Pages
- `index.html`: home page, overview of Einstein and ETH
- `pages/timeline.html`: timeline of his years in Zurich

## Layout
- `css/tokens.css` (Designer), `css/layout.css` (UI/UX), `css/site.css` (Lead Dev)
- `js/app.js` (Full-Stack), `js/nav.js` (UI/UX)
- `assets/`: original SVG illustrations

Plain HTML, CSS and JavaScript. No build step.
